# Digital Bar

Digital Bar es una aplicación web desarrollada con Next.js que permite a bares y restaurantes ofrecer una carta digital moderna, rápida y responsive mediante un código QR.

## Objetivos

- Carta digital responsive.
- Gestión sencilla de productos.
- Fotografías.
- Búsqueda y filtros.
- Pedidos desde el móvil.
- Panel de administración.
- Plataforma multi-restaurante.

## Tecnologías

- Next.js
- React
- TypeScript
- Tailwind CSS
